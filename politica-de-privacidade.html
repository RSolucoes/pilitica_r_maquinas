Politica de Privacidade

Aplicativo: R Maquinas X

Ultima atualizacao: 22/03/2026

Esta Politica de Privacidade descreve como o aplicativo R Maquinas X coleta, utiliza e protege informacoes dos usuarios durante o uso do sistema.

O aplicativo e destinado a operacoes internas relacionadas a maquinas, implementos, abastecimento, checklist, sincronizacao e rotinas operacionais.

1. Informacoes coletadas

O aplicativo pode coletar e processar os seguintes dados:

  • dados de autenticacao, como usuario e senha;
  • dados operacionais informados no uso do sistema;
  • identificadores de maquinas, equipamentos e QR Codes;
  • fotos capturadas no app, quando exigidas por processos internos;
  • dados de localizacao do aparelho, quando necessarios para registro e validacao de operacoes;
  • dados tecnicos do dispositivo e configuracoes utilizadas para funcionamento do aplicativo.

2. Uso das informacoes

As informacoes coletadas sao utilizadas para:

  • permitir o acesso autenticado ao sistema;
  • registrar abastecimentos, checklists e demais operacoes;
  • validar informacoes operacionais e auditorias internas;
  • realizar sincronizacao de dados com os sistemas utilizados pela empresa;
  • melhorar a seguranca, estabilidade e desempenho do aplicativo.

3. Permissoes utilizadas

O aplicativo pode solicitar as seguintes permissoes:

  • Camera: para leitura de QR Code e captura de fotos exigidas em operacoes e checklists;
  • Localizacao: para registrar a posicao aproximada ou precisa durante determinadas atividades;
  • Internet: para sincronizacao de dados e comunicacao com os servicos vinculados ao sistema.

4. Compartilhamento de dados

Os dados podem ser compartilhados apenas com sistemas, servidores, prestadores ou estruturas tecnicas necessarias para o funcionamento da plataforma e para o atendimento das finalidades operacionais do app.

Nao ha comercializacao de dados pessoais coletados pelo aplicativo.

5. Armazenamento e seguranca

Os dados podem ser armazenados localmente no dispositivo e/ou em ambientes controlados de processamento e sincronizacao. Sao adotadas medidas tecnicas e administrativas razoaveis para reduzir riscos de acesso nao autorizado, perda, alteracao ou divulgacao indevida.

6. Retencao de dados

Os dados permanecem armazenados pelo periodo necessario ao cumprimento das finalidades operacionais, obrigacoes legais, auditorias internas e continuidade do servico.

7. Direitos do usuario

O usuario pode solicitar esclarecimentos sobre o tratamento de seus dados e, quando aplicavel, solicitar atualizacao, correcao ou exclusao de informacoes, observadas as exigencias legais e operacionais aplicaveis.

8. Contato

Para duvidas sobre esta Politica de Privacidade ou sobre o tratamento de dados no aplicativo, utilize os canais oficiais da R Solucoes em Tecnologia LTDA.

Dominio de referencia do sistema: rsistemas.app.br

9. Alteracoes nesta politica

Esta politica pode ser atualizada periodicamente para refletir melhorias no aplicativo, mudancas operacionais, legais ou regulamentares. A versao mais recente sera a publicada neste endereco.
